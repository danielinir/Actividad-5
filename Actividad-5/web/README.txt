MODA URBANA — WEB PARA NETLIFY

Esta carpeta contiene la página web lista para publicar como sitio estático.

Publicación manual: en Netlify, arrastra esta carpeta web completa. El archivo de entrada es index.html. No necesita build ni comandos de instalación.

La página funciona sin dependencias locales. Los enlaces a fuentes externas requieren internet. El catálogo, la cesta, los pedidos simulados y el inventario se guardan en el almacenamiento local del navegador; no hay pagos, envíos ni sincronización entre dispositivos.
